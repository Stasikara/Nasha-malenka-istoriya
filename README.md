## 🚀 Як запустити проєкт локально

Сайт побудований на чистому **HTML5, CSS3 та Vanilla JavaScript**, тому не потребує Node.js або складного білду.

### Спосіб 1: Через локальний веб-сервер (Рекомендовано)

Для повноцінної роботи `fetch()` зовнішніх текстових файлів використовуйте простий локальний сервер:

#### Варіант A: Python (зазвичай вже встановлено в системі)
Відкрийте термінал / PowerShell у папці проєкту та виконайте:
```bash
python -m http.server 8000
```
Після цього відкрийте браузер за адресою: [http://localhost:8000](http://localhost:8000)

#### Варіант B: VS Code Live Server
1. Встановіть розширення **Live Server** у Visual Studio Code.
2. Клацніть правою кнопкою миші на `index.html` і виберіть **"Open with Live Server"**.

#### Варіант C: Node.js (npx serve)
```bash
npx serve .
```

### Спосіб 2: Пряме відкриття файлу
Ви також можете двічі клацнути на файл `index.html` у вашому провіднику Windows. Завдяки вбудованому механізму резервних даних (`js/data/`), усі спогади, фото та листи відкриються коректно навіть без веб-сервера.

## 📝 Список матеріалів, які можна персоналізувати або доповнити

Усі обов'язкові зображення (`photo-main.jpg`, 10 фотографій спогадів) та музичний трек (`lovesong.mp3`) вже наявні та інтегровані в сайт.

Для максимальної індивідуальності ви можете за бажанням відредагувати такі файли в папці `materials/`:

1. **`materials/letters/intro-letter.txt`** — текст листа, який відкривається одразу після конверта “To My Princess”.
2. **`materials/reasons/reasons.json`** — зараз містить приклад структури. Ви можете додати всі свої 365 унікальних причин у форматі:
   ```json
   [
     { "id": 1, "text": "Твоя усмішка..." },
     { "id": 2, "text": "Твої обійми..." }
   ]
   ```
3. **Листи в `materials/letters/`**:
   - `when-miss-me.txt`
   - `when-sad.txt`
   - `when-cant-sleep.txt`
   - `when-we-quarrel.txt`
   - `when-need-hug.txt`
4. **`materials/letters/final-message.txt`** — ваше особливе фінальне послання (завершується обов'язковими фразами «Я тебе кохаю, моя дівчинко ❤️» та «Завжди твій ❤️»).

## 🌐 Інструкція з безкоштовної публікації на GitHub Pages

Сайт повністю адаптований для безкоштовного розміщення на **GitHub Pages**:

1. **Створіть репозиторій на GitHub**:
   - Перейдіть на [github.com](https://github.com) і створіть новий публічний або приватний репозиторій (наприклад, `nasha-istoriya`).
2. **Завантажте файли сайту**:
   - Ініціалізуйте git у папці проєкту:
     ```bash
     git init
     git add .
     git commit -m "Initial commit: Наша маленька історія"
     git branch -M main
     git remote add origin https://github.com/ВАШ_НІК/nasha-istoriya.git
     git push -u origin main
     ```
   *(Або просто перетягніть файли через веб-інтерфейс GitHub).*
3. **Увімкніть GitHub Pages**:
   - У вашому репозиторії перейдіть у вкладку **Settings** (Налаштування).
   - У лівому меню виберіть розділ **Pages**.
   - У блоці **Build and deployment** під заголовком **Source** виберіть `Deploy from a branch`.
   - Для гілки вкажіть `main` і папку `/ (root)`.
   - Натисніть **Save** (Зберегти).
4. **Отримайте посилання**:
   - Через 1-2 хвилини на цій самій сторінці з'явиться готове посилання на ваш сайт вигляду:
     `https://ваш-нік.github.io/nasha-istoriya/`
